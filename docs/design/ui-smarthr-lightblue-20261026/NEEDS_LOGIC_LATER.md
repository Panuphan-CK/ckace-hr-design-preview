# NEEDS_LOGIC_LATER

ข้อมูลส่วนนี้ต้องมาจาก API หรือแหล่งข้อมูลที่ได้รับอนุมัติ ห้ามใช้ตัวเลขหรือตัวอย่างจาก mock-up แทนข้อมูลจริง

| รายการที่ยังไม่แสดง | เหตุผลที่ซ่อนไว้ | ต้องมีอะไรจึงแสดงได้ |
| --- | --- | --- |
| จำนวนพนักงานทั้งหมด แยกแผนก สถานะพร้อมทำงาน และสัดส่วนการเข้างานในแดชบอร์ดผู้ดูแล | หน้าภาพรวมปัจจุบันมีข้อมูลสิทธิ์และคำขอของบัญชีที่เข้าสู่ระบบกับปฏิทินการลาของทีม แต่ไม่มี endpoint สำหรับสรุปพนักงาน/เวลาเข้างานทั้งองค์กร | API รายงานสรุปพนักงานและ attendance ตามขอบเขตสิทธิ์ของผู้ใช้ |
| กิจกรรมล่าสุด วันเกิด และวันสำคัญของพนักงาน | ข้อมูลที่มีอยู่ไม่ครอบคลุม activity feed และวันเกิด; ห้ามใช้แถวตัวอย่างจาก SmartHR mock-up | API ที่ให้รายการพร้อมวันที่และสิทธิ์การมองเห็น |
| รายการลาทั้งบริษัทในหน้า leave list | หน้าสถานะคำขอคืนรายการของผู้ใช้ปัจจุบันและรวมหลายประเภทคำขอ ไม่มีข้อมูลลาแบบทั้งองค์กรในหน้านี้ | API รายการลาสำหรับผู้ดูแล พร้อม filter, pagination และ permission ที่กำหนด |
| ข้อมูลค้นหาทั่วทั้งระบบจากช่องค้นหาบน top bar | แสดงช่องค้นหาเป็นองค์ประกอบภาพเท่านั้น ช่องเป็น read-only เพราะยังไม่มี search handler หรือ API; ไม่มีการเพิ่มการค้นหา | ขอบเขตข้อมูลที่ค้นหาและ endpoint พร้อม permission rules |
| รูปภาพพนักงานในตารางรายชื่อ | หน้าจัดการใช้เฉพาะข้อมูลที่ API ส่งให้; ไม่มีการสร้างรูปหรือใช้รูปตัวอย่างจาก mock-up | API โปรไฟล์ที่คืน URL รูปซึ่งผ่านการตรวจ permission |
| เวลาเฉลี่ยตอบอนุมัติ | API ที่หน้าการลามีอยู่ไม่ได้ให้ค่าเฉลี่ย response time | API ที่เป็นแหล่งจริง พร้อมนิยามและสิทธิ์การมองเห็น |
| สรุปการเข้างานทั้งองค์กรบนแดชบอร์ด | หน้าลงเวลาปัจจุบันเป็นข้อมูลและปุ่มของผู้ใช้ที่เข้าสู่ระบบ; ข้อมูลรวมอยู่ในหน้ารายงานตาม API ที่มีเท่านั้น | endpoint ภาพรวม attendance พร้อมสิทธิ์และนิยามตัวชี้วัด |
| เอกสาร/ข้อกำหนดการลา | หน้าเว็บไม่มี endpoint หรือ URL เอกสารที่อนุมัติแล้ว จึงซ่อนการ์ด placeholder ที่เคยแสดงว่าไม่มีข้อมูล | API หรือ URL เอกสารฉบับจริง พร้อมสิทธิ์การมองเห็น |
